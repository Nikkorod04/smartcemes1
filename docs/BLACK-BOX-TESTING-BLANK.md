# Black Box Testing

In the black box testing, the code and internal structure are not known to the end-user. This is often done by a non-IT end user, who focuses on the functional requirement of the system. The researchers decided to use the Decision Table as a black-box technique, which consisted of conditions that are represented in the rows and column headings. On the other hand, actions are represented as the intersection points of the conditional cases in the table.

**System under test:** SmartCEMES — AI-Powered Community Extension Monitoring and Evaluation System, Leyte Normal University (CESO).
