
2\. F-CES-001-Community Needs Assessment

This form is a comprehensive **Needs Assessment Survey Form** (mostly in Waray-Waray, translated to English below).

| Section/Field Name | Control Type (Laravel Equivalent) | Notes (Translated) |
| :---- | :---- | :---- |
| **I – Identifying Information** |  |  |
| respondent\_name | Text Input | Name of Respondent (Ngaran) |
| age | Number Input | Age (Edad) |
| civil\_status | Text Input | Civil Status |
| sex | Select/Radio | Sex |
| religion | Text Input | Religion |
| educational\_attainment | Checkbox Group | Elementary, High School, College (An Natapos) |
| **II – Family Composition (Table)** | Repeating Group | **Table for each family member:** Name, Age, Sex, Educational Attainment, Employment |
| **III – Economic Aspect** |  |  |
| livelihood\_options | Checkbox Group | **Panginabuhi hit Pamilya:** Farming, Raising animals, Selling, Driving, Remittance, Pension, 4Ps, Rentals, Service Work, Other (Specify) |
| interested\_in\_training | Radio Button | Do you want training for livelihood? (Oo/Diri) |
| desired\_training | Checkbox Group/Text Input | **If Yes:** Cosmetology, Handicrafts, Electronics, Computer, Refrigerator & A/C, Food Processing, Dress Making, Pananom, Other (Specify) |
| **IV – Educational Aspect** |  |  |
| barangay\_facilities | Checkbox Group | Daycare, Elementary (Primary/Intermediate), Secondary, College |
| household\_member\_studying | Radio Button | Is anyone in the household currently studying? (Oo/Waray na) |
| interested\_in\_continuing\_studies | Radio Button | Interested in continuing studies? (Oo/Diri) |
| areas\_of\_interest | Checkbox Group/Text Input | Reading, Writing, Math, English, Issues, Laws, Other (Specify) |
| preferred\_time | Radio Button | Morning (8:00-12:00) or Afternoon (1:30-5:00) |
| preferred\_days | Checkbox Group | Wednesday, Saturday, Sunday |
| **V – Health, Sanitation, Environmental** |  |  |
| common\_illnesses | Checkbox Group/Text Input | Colds, Flu, Asthma, Pneumonia, Diarrhea, Schistosomiasis, Hypertension, Diabetes, Vomiting, Headache, Stomach Ache, Other (Specify) |
| action\_when\_sick | Checkbox Group/Text Input | Hospital/Health Center, Herbal Medicine, Albularyo, Hilot, Other (Specify) |
| barangay\_medical\_supplies | Checkbox Group/Text Input | Ambulance, Health Center, Medical Equipment, Other (Specify) |
| has\_barangay\_health\_programs | Radio Button | Are there Barangay Health Programs? (Oo/Diri) |
| benefits\_from\_programs | Radio Button | Does household benefit from them? (Oo/Diri) |
| programs\_benefited | Checkbox Group/Text Input | **If Yes:** Free Vaccine, Free Consultation, Pre-natal check-up, Check-up, Free Medicine, Other (Specify) |
| water\_source | Checkbox Group/Text Input | NAWASA, Water Pump, Deep Well, Spring Water, River/Stream, Other (Specify) |
| water\_source\_distance | Radio Button | Just outside, 250 meters away, No idea |
| garbage\_disposal | Checkbox Group/Text Input | Compost pit, Anywhere, In the river, Vacant lot, Other (Specify) |
| has\_own\_toilet | Radio Button | Do you have your own toilet? (Mayda/Waray) |
| toilet\_type | Checkbox Group/Text Input | **If Yes:** Flush toilet, Water sealed (di buhos), Antipolo style, Other (Specify) |
| keeps\_animals | Radio Button | Do you keep animals? (Mayda/Waray) |
| animals\_kept | Checkbox Group | **If Yes:** Dog, Duck, Chicken, Cat, Other |
| **VI – Housing and Basic Amenities** |  |  |
| house\_type | Checkbox Group | Wood/Bamboo, Makeshift, Wood, Half concrete/wood, Nipa/Bamboo, All concrete |
| tenure\_status | Checkbox Group/Text Input | Own house/land, Own house/rent land, Rent house, NGO/Gov’t given, Squatter, Other (Specify) |
| has\_electricity | Radio Button | Do you have electricity? (Oo/Waray) |
| light\_source\_no\_power | Checkbox Group | **If No:** Oil lamp, Candle, Solar lamp |
| appliances | Checkbox Group/Text Input | **If Yes (Power):** TV, Stove, Washing Machine, Gas Range, Refrigerator, Flat Iron, Rice Cooker, Computer, Electric Fan, Karaoke, Oven Toaster, Other (Specify) |
| **VII – Recreational Facilities** |  |  |
| barangay\_recreational\_facilities | Checkbox Group/Text Input | Basketball Court, Volleyball Court, Tennis Court, Soccer Field, Other (Specify) |
| use\_of\_free\_time | Checkbox Group/Text Input | Playing basketball, Watching TV, Playing cards, Radio drama, Chatting, Sleeping, Staying home, Other (Specify) |
| member\_of\_organization | Radio Button | Member of an organization? (Oo/Waray) |
| group\_type | Checkbox Group/Text Input | **If Yes:** Civic, Religious, LGU, Cultural, Sports/Recreational, Other (Specify) |
| meeting\_frequency | Radio Button | Weekly, Monthly, Twice a month, Yearly |
| usual\_activities | Textarea | Activities usually done by the group |
| household\_member\_in\_group | Checkbox Group/Text Input | Self, Spouse, Child, Other (Specify) |
| position\_in\_group | Radio Button/Text Input | Official, Member, Other (Specify) |
| **VIII – Other Needs & Problems** |  | **Checkboxes for each category, plus 'Other (Specify)'** |
| problems\_family | Checkbox Group/Text Input | Cannot support family needs, Separated couple, Domestic violence, Poor family relationship, Other |
| problems\_health | Checkbox Group/Text Input | Sickly children, House near dumpsite, Lack of health education/equipment/personnel, Malnourished, Disease outbreak, Other |

| problems\_employment | Checkbox Group/Text Input | Lack of employment, Lack of skills, No receiving agency, Other |
| problems\_infrastructure | Checkbox Group/Text Input | Difficult roads, No irrigation/waiting shed/post harvest equipment/electric posts/strong bridge, Lack of classroom, Other |
| problems\_economy | Checkbox Group/Text Input | Lack of buyers, No capital, No product transport, No livelihood ideas, Many dependents, Other |
| problems\_security | Checkbox Group/Text Input | Always noisy, No police assigned, Theft, Other |
| **IX – Summary** |  |  |
| barangay\_service\_ratings | Radio/Select (1-5 scale) | **Nine separate ratings** for services like Law Enforcement, Fire Protection, BNS Service, etc. |
| general\_feedback | Textarea | Comment/Feedback on providing programs/livelihood |
| available\_for\_training | Radio Button | Are you available for training? (Oo/Diri) |
| reason\_not\_available | Textarea | **If No:** Why are you not available? |
